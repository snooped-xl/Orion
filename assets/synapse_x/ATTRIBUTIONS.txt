Source paths:

  theme defaults, layout metrics, and transitions)

- src/editor/monacoThemePack.ts and tomorrow-night-eighties.theme.json

UI font: Inter (shared assets/synapse_v3/fonts). Original Linux browser
reference reports Inter Regular via CSS.getPlatformFontsForNode for source
chrome, actions, and tabs. License: fonts/Inter-OFL.txt (SIL Open Font License).

Editor font: Liberation Mono Regular/Bold/Italic/BoldItalic. This reproduces
Courier New's actual Linux fallback in the original Consolas/Courier New
Monaco stack, confirmed by CSS.getPlatformFontsForNode on the source editor.
License and copyright notices: fonts/LiberationMono-LICENSE.txt. Native
Monaco serves identical fonts offline from assets/editor/fonts.

Optional system Segoe UI fallback: Cantarell Regular/Bold. The source names
Segoe UI in its WPF CSS; Cantarell is retained as a redistributable fallback.
Actual source UI defaults use Inter as noted above. License and copyright
notices: fonts/Cantarell-LICENSE.txt (SIL Open Font License).

Original monaco-themes JSON package (MIT) is bundled offline in
assets/editor/synapse-skins.js; its license is assets/editor/MONACO-THEMES-LICENSE.
No execution backend or automatic attachment/open/execution is included.
